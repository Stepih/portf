# Видео первого экрана

Своё видео, источник не указан.

## Как собраны кадры

- Исходник: видео, промежуточные кадры дорисованы до 48 к/с (--interpolate)
- Десктоп: 476 кадров 1280×720, 10.9 MB, WebP quality=82
- Телефон: 239 кадров 1280×720, 5.5 MB, WebP quality=82
- Точка кадрирования на узком экране: 0.5, 0.5
- Команда: `npm run hero:prepare -- apartment_kling4_16x9.mp4 --interpolate 48 --format webp --width 1280 --frames 479 --max-mb 14 --mobile-width 1280 --mobile-frames 240 --mobile-max-mb 6`

## Как заменить своим видео

```sh
npm run hero:prepare -- путь/к/видео.mp4
```

Скрипт удалит старые кадры, нарежет новые и перепишет manifest.json. Пояснения к деталям видео
(тексты, точки и окна прогресса) лежат в src/shared/hero/notes.ts — их нужно поправить под новое видео.
